# scSimEvalStudio: Interactive Shiny Studio for scSimEval Single-Cell Multiomics Benchmarking

Companion graphical Shiny web interface for the 'scSimEval' Bioconductor
package. Enables interactive uploading of single-cell RNA-seq,
scATAC-seq, and paired or unpaired multiomics SingleCellExperiment
datasets, execution of the 56-measure evaluation suite, interactive
bubble-matrix and ordination exploration, and export of
publication-quality figures and tabular reports.
