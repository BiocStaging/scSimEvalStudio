# scSimEvalStudio: Interactive Shiny Studio for scSimEval Single-Cell Multiomics Benchmarking

Companion graphical Shiny web interface for the `scSimEval` Bioconductor package (v0.99.12). Enables interactive uploading of single-cell RNA-seq, scATAC-seq, and paired or unpaired multiomics `SingleCellExperiment` datasets, execution of the 56-measure evaluation suite across 8 canonical categories, interactive bubble-matrix and ordination exploration, and export of publication-quality figures, standalone HPC R scripts, and tabular reports.
