Functions to start and inspect the interactive `scSimEvalStudio` Shiny app (companion to [`scSimEval`](https://kabilanbio.github.io/scSimEval/reference/index.html) v0.99.12).

- [`launch_scSimEval_app()`](https://kabilanbio.github.io/scSimEvalStudio/reference/launch_scSimEval_app.md) : Launch Interactive scSimEval Benchmarking Studio
- [`scSimEvalStudio`](https://kabilanbio.github.io/scSimEvalStudio/reference/scSimEvalStudio-package.md) [`scSimEvalStudio-package`](https://kabilanbio.github.io/scSimEvalStudio/reference/scSimEvalStudio-package.md) : scSimEvalStudio: Interactive Shiny Studio for scSimEval Single-Cell Multiomics Benchmarking
